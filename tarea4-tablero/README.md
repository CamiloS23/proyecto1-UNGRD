# Tarea 4 - Diseño del tableroEste sería el diseño del tablero para la parte de contratación. ¿Cómo funciona? Inicialmente, se puede filtrar por el tipo de modalidad de contratación, con un menú desplegable en el que están todas las opciones disponibles. Así, el usuario puede ver la cantidad de contratistas dentro de una modalidad específica. También se puede cambiar la cantidad de datos que se muestran: dentro de nuestro código mostramos el top 10, pero se puede consultar el top 15, el top 5, el top 20, etc. Y también se puede buscar por nombre, tanto de entidad como de persona.
